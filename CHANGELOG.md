# Changelog

All notable changes to the CE-RISE SEE Impacts Calculation Service will be documented in
this file.

## [0.0.1] - Unreleased

### Added
- Containerized API for single-indicator environmental calculations from CE-RISE inputs, with HEX Core input and output validation.
- Bundled BONSAI background preparation, Brightway compatibility checks, and method discovery.
- Isolated per-request calculations with bounded concurrency, singularity diagnostics, and method and data provenance in results.
- End-to-end PV calculation test using the bundled BONSAI background and published CE-RISE data models.
